Setup

From nothing to a pocket agent in about five minutes. You need an iPhone and a Mac (or Linux box) that stays on.

1Install Hermes + the tealclaw profile

TealClaw talks to a Hermes agent gateway. Create the profile that exposes the bridge:

# clone hermes + create the profile
hermes profile create tealclaw
# drop in the tealclaw platform plugin (bridge + skills)
# full guide: github.com/Snail3D/tealclaw → ios/README

The profile ships with a SOUL (Trey 🦞), the tealclaw skill, and the bridge plugin the app connects to.

2Start the gateway

# run the gateway for the tealclaw profile
hermes --profile tealclaw gateway

You'll see the bridge listening — default port 8720. Leave it running (launchd/systemd recommended).

3Connect the app

Open TealClaw on your iPhone → Settings → paste your Bridge URL (e.g. http://your-mac:8720 or a Tailscale hostname) and the bridge token from the profile's config.yaml.

💡 Tap Test connection — a green check means the agent is live. Outside your LAN? Install Tailscale on both devices and use the tailnet name — zero port-forwarding.

4Allow notifications

First launch asks for notification permission — say yes. That's how your agent reaches you while the app is closed, including cron-job deliverables (it's the agent's home channel).

🔐 Voice requires a whisper/STT + TTS endpoint if you don't run defaults — see the README's voice section. On-device speech transcription works out of the box.

5Talk to it

Hold the claw ~1 second until it pulses, talk, release. Words typewrite into the field — or swipe up while holding to send directly. Try: "make me a game", "what's on my calendar", or send a photo of something and ask about it.

Stuck? Open an issue — the claw usually answers within the day.
