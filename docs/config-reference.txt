# TealClaw Config Reference — Complete Field Guide

> Full documentation for every configurable field in TealClaw.
> Main skill guide: https://tealclaw.ai/llms.txt

TealClaw uses partial merge — only include fields you want to set or change.
All values are stored in browser localStorage. No server, no database.

## Delivery Methods

1. **Settings UI (recommended on mobile)**: Settings → Telegram Relay Setup (includes Quick Setup Wizard)
2. **URL hash**: `https://tealclaw.ai/#config=BASE64_JSON` (best link-based import)
3. **JSON file**: Drag a `.json` file into the TealClaw chat
4. **Chat paste**: Paste raw JSON into the chat input
5. **Bare key**: Paste a single API key (auto-detected by prefix)

### Import Reliability (v1.1)

Encrypted config imports now verify each applied field after save.
If any field fails to persist (including sensitive keys on mobile), TealClaw shows:
- exact field-level failure list
- clear reason per field
- **Retry Failed Keys** action

## API Provider Fields

| Field | Type | Description |
|-------|------|-------------|
| aiProvider | "groq" | AI provider for chat completions |
| aiKey | string | API key for chat. Prefixes: gsk_* (Groq) |
| aiModel | string | Model ID. Default: groq/compound-mini |
| whisperKey | string | Groq API key for Whisper voice transcription, Orpheus TTS, AND /research command. Get free at console.groq.com |
| groqTtsVoice | string | Groq Orpheus TTS voice name. Options: autumn, diana, hannah, austin, daniel, troy. Default: troy |
| ttsAutoPlay | boolean | Auto-speak AI responses. Default: true. Set false for on-demand playback (tap to hear) |
| maxTokens | number | Max tokens per AI response. Default: 400. Range: 50-2000 |
| temperature | number | AI creativity. 0=focused, 2=creative. Default: 0.7 |

## System Prompt & Mode

| Field | Type | Description |
|-------|------|-------------|
| sysPrompt | string | System prompt sent to the AI. Supports any instructions, persona, etc. |
| mode | "direct" / "agent" / "telegram-relay" | Direct = browser calls provider API. Agent = route through OpenClaw gateway. Telegram Relay = Telegram is primary chat transport |
| allowProactiveCameraCapture | boolean | Default: true. If true, incoming `tc-action` `camera.capture` and `screen.capture` use lightweight inline consent (Take photo / Take screenshot / Cancel). If false, uses full confirm modal flow. |

## Agent Camera Routing (Operational Guidance)

When `mode` is `"agent"` and TealClaw is connected to OpenClaw:
- Use `/photo` (or `/capture` / `/takephoto`) for one-off camera snapshots via `camera.capture`.
- Use `/screenshot` (or `/screen` / `/capture-screen`) for one-off display captures via `screen.capture`.
- Use Overwatch/watch flows for persistent monitoring and recurring alerts.
- Facing guidance: `environment` for scenes/objects, `user` for selfie/face checks.
- Route retained stills into photo-log when users ask to archive/review captures (v2 target behavior).
- Proto-BOLO is intended for watchlist matching workflows (v3 target).
- Always require user consent/authority before camera capture or monitoring.
- `allowProactiveCameraCapture` (default true): show inline consent UI for `camera.capture` and `screen.capture` requests (Take photo / Take screenshot / Cancel). If false, keep strict confirm modal.

## Multi-Model Routing

| Field | Type | Description |
|-------|------|-------------|
| fastModel | string | Model ID for quick/simple messages. Used when message is short and simple |
| complexModel | string | Model ID for complex messages. Used when message contains analytical keywords or is long |
| routingThreshold | number | Character length threshold to trigger complex model. Default: 80 |

Routing logic: messages under `routingThreshold` chars without complex keywords (explain, analyze, compare, etc.) use `fastModel`. Others use `complexModel`. If neither is set, the default model is used.

## Security

| Field | Type | Description |
|-------|------|-------------|
| pinHash | string | SHA-256 hash of the PIN, set automatically via Settings > Password Lock |
| pinRequired | boolean | Whether PIN is required to send messages. Default: false |

PIN supports 4-8 characters (alphanumeric). Set the PIN via Settings > Password Lock — TealClaw stores only the SHA-256 hash, never the plaintext. Protects against unauthorized use on shared or unlocked devices. API keys are never included in QR code exports.

## Gesture Control

Camera-based hand gesture recognition using MediaPipe Hands. Detects hand landmarks from the selfie cam and triggers configurable actions.

| Field | Type | Description |
|-------|------|-------------|
| gestureEnabled | boolean | Enable The Claw hand gesture mode. Shows a floating pip with camera feed and hand tracking overlay |

## Rate Limiting

| Field | Type | Description |

| rateLimitPerMin | number | Maximum messages per minute. Default: not set (unlimited). Prevents runaway API costs |

## Key Auto-Detection Prefixes

When a bare key is pasted (no JSON), TealClaw auto-detects:
- gsk_* → whisperKey (Groq — also enables Orpheus TTS)
- sk-or-v1-* → imageGenKey (OpenRouter)
- AIza* → imageGenKey (Google AI / Nano Banana)
- 123456:ABC-* → tgToken (Telegram bot)
- Negative or 6+ digit number → tgChatId
- http(s)://...:port → gateway URL
- 32+ hex chars → gateway token
