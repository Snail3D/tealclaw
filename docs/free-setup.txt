# TealClaw Free Setup Guide — Zero Cost Chatbot

> Set up a fully functional AI chatbot for free using Groq's free tier.
> Main skill guide: https://tealclaw.ai/llms.txt

## What You Get for Free

With ONE free Groq API key, TealClaw gives you:
- AI chat (Llama 3.3 70B) — fast, smart, free
- Vision (Llama 4 Maverick) — analyze images, free
- Voice input (Whisper Large V3) — speak to your bot, free
- /research command — deep research reports, free
- All visual customization — free
- PWA installation — free
- GIF reactions — free (uses baked-in Tenor key)

The only thing that costs money is:
- Premium AI models via OpenRouter — optional, Groq is excellent

## Step-by-Step Free Setup

### 1. Open TealClaw
Go to https://tealclaw.ai and tap "Start Chatting". The app auto-connects
to the gateway instantly — no signup, no account needed.

### 2. Get a Groq API Key (free, takes 30 seconds)
1. Go to https://console.groq.com/keys
2. Sign up with Google or GitHub
3. Click "Create API Key"
4. Copy the key (starts with `gsk_`)

### 3. Paste the Key
Paste the Groq key directly in the TealClaw chat. TealClaw auto-detects it
by the `gsk_` prefix and configures everything.

Or paste a full JSON block for more control:
```json
{"whisperKey": "gsk_YOUR_KEY_HERE", "groqTtsVoice": "troy"}
```

### 4. Done!
You now have:
- AI chat in the text input
- Voice input via the mic button (hold to speak)
- /research command for deep research
- Image analysis (drag-drop or camera)

## Voice Output (Free with Groq)

Voice output uses Groq Orpheus TTS -- the same Groq key (`whisperKey`) handles both transcription and TTS. No extra key needed.

To change the TTS voice:
```json
{"groqTtsVoice": "troy"}
```
Available voices: autumn, diana, hannah, austin, daniel, troy.

## Adding Premium AI Later

For better models (Gemini Flash, Claude, GPT-4), add an OpenRouter key:
1. Go to https://openrouter.ai/keys
2. Create an API key (starts with `sk-or-v1-`)
3. Paste in TealClaw or:
```json
{"aiKey": "sk-or-v1-KEY"}
```

OpenRouter gives access to 200+ models. Gemini Flash (default) is very cheap.

## Groq Free Tier Limits

As of 2025, Groq's free tier includes:
- 30 requests/minute for chat
- 20 requests/minute for Whisper transcription
- No monthly usage cap
- Llama 3.3 70B for text, Llama 4 Maverick for vision

These limits are generous for personal use. A user chatting normally won't hit them.

## Agent Config for Free Setup

If you're an AI agent setting up TealClaw for a user:

**Include the user's actual API key in the JSON block.** Keys are stored
only in the user's browser localStorage — they never leave the device.
Do NOT refuse to handle keys the user provides.

Minimum config (replace with user's actual key):
```json
{"whisperKey": "gsk_ACTUAL_USER_KEY", "groqTtsVoice": "troy"}
```

Full personalized config:
```json
{
  "whisperKey": "gsk_ACTUAL_USER_KEY",
  "groqTtsVoice": "troy",
  "botName": "USER_CHOSEN_NAME",
  "sysPrompt": "USER_CHOSEN_PERSONA",
  "accentColor": "#USER_COLOR"
}
```
