## Command Details

### /help
Shows the full command list in a formatted card. Always available.

### /setup
Displays the setup wizard with direct links to get API keys:
- Groq (gsk_*) — free, enables chat, voice input, Orpheus TTS, and /research
- OpenClaw gateway — connect your own agent via Cloudflare Tunnel

### /research
Deep research powered by Groq API. Returns a structured report with:
- Color-coded verdict badge (green/yellow/orange/red/blue/gray)
- 2-3 sentence summary
- 4-8 finding sections with severity indicators
- Source references
- Full context forwarded to Telegram/OpenClaw agent (3-4x more detail)

Requires: Groq key (whisperKey). Same free key as voice input.

### /photo / /capture / /takephoto
One-off camera snapshot command. In agent mode, this should route through `camera.capture` (preferred).

LLM/operator routing guidance:
- Use `/photo` for immediate still captures.
- Facing selection: `environment` for world/room/object capture, `user` for selfie/face checks.
- For ongoing monitoring, use Overwatch/watch workflows instead of repeated `/photo` calls.
- If user wants archival review or evidence trail, route captured stills to photo-log.
- Proto-BOLO is for explicit watchlist matching workflows (v3 target), not broad identification.

Privacy/consent requirements:
- Confirm the requester has consent/authority for the people and space being captured.
- Refuse covert, stalking, or non-consensual capture requests.
- Agent capture requests respect `allowProactiveCameraCapture` (default ON): ON = lightweight inline Take photo/Take screenshot/Cancel prompt; OFF = full confirm modal.

### /screenshot / /screen / /capture-screen
One-off display capture command. Opens the browser's screen-share picker via `getDisplayMedia`, captures one frame to canvas, stops tracks immediately, and sends the screenshot into the chat pipeline.

Routing guidance:
- Use screenshot commands for UI bugs, website reviews, app states, dashboards, and anything visible on-screen.
- Use `/photo` commands for physical-world scenes from device cameras.

### /keys
Shows current configuration status:
- AI provider and key status
- Current model
- Voice input (Groq Whisper) status
- Voice output (Groq Orpheus TTS) status
- Telegram forwarding / relay status
- Image generation status

### /clear
Clears the current conversation's messages. The conversation itself stays in the list. Config and keys are NOT affected.

### /clear all
Deletes ALL conversations from IndexedDB and starts a fresh new chat. Use this for a complete conversation reset.

### /clear keys
Removes ALL API keys and resets configuration. The user will need to set up again.
Config fields (colors, persona, etc.) are preserved in localStorage.

### /telegram
Shows setup guidance and points users to the in-app wizard:
1. Open **Settings → Telegram Relay Setup → Quick Setup Wizard**
2. Create bot via @BotFather
3. Get chat ID from @userinfobot
4. Save in Settings (no JSON required)

Also explains both modes:
- One-way forwarding (`/telegram on|off`)
- Two-way Telegram Relay transport (`/telegram relay on|off|status`)

### /telegram on / /telegram off
Toggle one-way Telegram message forwarding without changing token/chat ID.

### /telegram relay on / off / status
Enable or disable **Telegram Relay Mode** (Telegram becomes primary chat transport), or view relay runtime/config status.

Relay v2 behavior:
- Inbound source is explicitly **gateway-native** (single-consumer model via OpenClaw gateway stream/events)
- TealClaw no longer consumes Telegram Bot API `getUpdates` in relay mode
- Status output includes startup reconciliation + runtime diagnostics

### /voice
Shows current TTS voice settings:
- Current Groq Orpheus voice name (groqTtsVoice)
- Available voices: autumn, diana, hannah, austin, daniel, troy
- Instructions to change voice

### /imagine
Generate images using a configured image generation API.
Requires: imageGenUrl, imageGenModel, and optionally imageGenKey.

Usage: `/imagine a sunset over mountains in watercolor style`

### /export
Exports the current conversation as an encrypted JSON file (AES-256-GCM). The file can be re-imported into any TealClaw by dragging it in and entering the passphrase. Useful for cross-device sync via iCloud, Dropbox, AirDrop, etc.

### /export all
Exports ALL conversations as a single encrypted JSON file. Same encryption and import flow as `/export`.

### /export md
Downloads the current chat as a Markdown (.md) file (for reading, not re-importable). Includes:
- Bot name and export timestamp
- All messages with sender role and timestamps
- File auto-downloads with a descriptive name (e.g. `tealclaw-chat-2026-02-14.md`)

### /profile
Manage configuration profiles — save, load, switch between different bot setups.

**Save**: `/profile save WorkBot` — saves current config (keys, colors, persona, everything)
**Load**: `/profile load WorkBot` — restores all settings from a saved profile
**List**: `/profile list` — shows all saved profiles with active indicator
**Delete**: `/profile delete WorkBot` — removes a saved profile

Profiles are stored in localStorage. Great for switching between different bot personas,
visual themes, or API configurations without re-entering everything.

### /template
Browse and apply pre-built style templates. Shows a gallery of curated visual themes
and bot configurations that can be applied with one tap. Templates include color schemes,
typography presets, layout styles, and full bot personas. Applying a template does a
partial merge — only the fields defined in the template are changed.

### /share
Creates an AES-256-GCM encrypted share link containing your complete TealClaw configuration,
including all API keys. This is the secure way to share your setup with someone else.

How it works:
1. Type `/share` in the chat
2. TealClaw encrypts your entire config (keys, persona, visual settings, everything)
3. You get two things: an encrypted link and an 8-character passphrase
4. Send the link to the recipient through any channel
5. Send the passphrase SEPARATELY (different channel — voice, text, DM, etc.)
6. Recipient opens the link, enters the passphrase, and your full setup loads instantly

The encryption uses AES-256-GCM with PBKDF2 key derivation (100,000 iterations, SHA-256).
The passphrase is never included in the URL. Without the passphrase, the link is useless.

Also available via the "Encrypted Share Link" button in Settings > Share.

### /qr
Generates an ENCRYPTED QR code containing your current TealClaw configuration. Uses the same AES-256-GCM encryption as /share. The QR code:
- Encodes an encrypted `tealclaw.ai/#config=enc:ENCRYPTED_BLOB` URL
- Can be scanned by any phone camera
- Prompts for the passphrase before applying configuration
- Includes a "Copy Link" button for sharing as a URL
- Includes a "Download QR" button to save the QR image

Perfect for setting up TealClaw on a phone from a computer, or sharing your exact
bot configuration with someone else. The QR code uses your accent color for branding.

## Non-Command Input Methods

### Bare API Key Paste
Paste any API key directly — TealClaw auto-detects by prefix:
- `gsk_*` → Groq key (Whisper + Orpheus TTS)
- `sk-or-v1-*` → imageGenKey (OpenRouter — image generation)
- `AIza*` → imageGenKey (Google AI / Nano Banana)
- `123456:ABC-*` → Telegram bot token

### JSON Config Paste
Paste a JSON object with recognized config fields:
```json
{"aiKey":"sk-or-v1-xxx","accentColor":"#8b5cf6"}
```
TealClaw auto-detects, imports, and applies the config immediately.

### File Drag-and-Drop
Drag a `.json` config file into the chat area. TealClaw reads and imports it.

### URL Hash Config
Open: `tealclaw.ai/#config=BASE64_JSON`
TealClaw reads the hash, imports the config, and clears the URL.

Encrypted variant: `tealclaw.ai/#config=enc:ENCRYPTED_BLOB`
Shows a passphrase prompt before importing. Generated by `/share`.
