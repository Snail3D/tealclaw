TealClaw

BYOK voice AI dashboard. Zero server. Total privacy. 110+ configurable fields.

TealClaw is a Progressive Web App that runs entirely in your browser. Your API keys never leave your device. All API calls go directly from your browser to the AI provider.

Features

  • Multi-turn chat with streaming and typing animations
  • Voice input (Groq Whisper) and output (Groq Orpheus TTS)
  • Image generation (/imagine) and vision (camera, drag-drop, paste)
  • Deep research reports (/research) with segmented results
  • 12 built-in style templates (/template)
  • Custom bot persona -- name, icon, greeting, system prompt
  • Full visual customization -- colors, fonts, backgrounds, animations
  • Multi-conversation with IndexedDB, encrypted export/import
  • Config profiles, QR code sharing, Telegram forwarding
  • Multi-model routing, LaTeX rendering, GIF reactions, rate limiter
  • PIN code security, accessibility features, PWA installable

For AI Agents

The complete agent skill guide is at tealclaw.ai/llms.txt. Any AI agent can read that file to learn how to configure TealClaw via JSON. A single JSON config block in a chat response auto-applies all settings in real time.

Config delivery methods: inline JSON (auto-applied), config file (drag-drop), or URL hash (tealclaw.ai/#config=BASE64).

Source code and skill files are on GitHub at github.com/Snail3D/tealclaw. The SKILL.md file contains the full agent skill definition with config schema, delivery methods, recipes, and troubleshooting.

TealClaw

Created by Snail
Free, open-source, and provably anonymous forever.

TealClaw started as a simple idea: what if you could have a fully customizable AI chat interface that runs entirely in your browser, with no server, no accounts, and no data collection?

Every feature — from voice I/O to streaming, templates, GIF reactions, interactive components, and 110+ config fields — was built with one goal: give you complete control over your AI experience.

Your API keys never leave your device. Your conversations stay in your browser. TealClaw is and always will be free to use.

More than a chatbot

Connect to OpenClaw and TealClaw becomes a full control surface — your AI can manage smart devices, run automations, monitor cameras, stream video, and execute real-world actions through the tc-action protocol. Create guest links for family. Deep research with live sources. It's an AI dashboard that does whatever you build it to do.
