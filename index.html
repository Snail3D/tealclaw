TealClaw

BYOK voice AI dashboard. Zero server. Total privacy. 95+ configurable fields.

TealClaw is a Progressive Web App that runs entirely in your browser. Your API keys never leave your device. All API calls go directly from your browser to the AI provider.

Features

  • Multi-turn chat with streaming and typing animations
  • Voice input (Groq Whisper) and output (ElevenLabs TTS)
  • Image generation (/imagine) and vision (camera, drag-drop, paste)
  • Deep research reports (/research) with segmented results
  • 12 built-in style templates (/template)
  • Custom bot persona -- name, icon, greeting, system prompt
  • Full visual customization -- colors, fonts, backgrounds, animations
  • Config profiles, QR code sharing, Telegram forwarding
  • Multi-model routing, LaTeX rendering, GIF reactions
  • PIN code security, accessibility features, PWA installable

For AI Agents

The complete agent skill guide is at tealclaw.ai/llms.txt. Any AI agent can read that file to learn how to configure TealClaw via JSON. A single JSON config block in a chat response auto-applies all settings in real time.

Config delivery methods: inline JSON (auto-applied), config file (drag-drop), or URL hash (tealclaw.ai/#config=BASE64).

Source code and skill files are on GitHub at github.com/Snail3D/tealclaw. The SKILL.md file contains the full agent skill definition with config schema, delivery methods, recipes, and troubleshooting.
